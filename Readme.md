
# 🏋️ FitVerse

FitVerse is a responsive, front-end fitness website built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. It showcases workout plans, diet guides, community features, and success stories — all wrapped in a clean, modern UI with no external frameworks or backend dependencies.

## 🌐 Live Demo

https://cheshta02.github.io/fitverse/

## 📁 Project Structure

FitVerse/
├── index.html         # Home page
├── about.html          # About us page
├── workout.html        # Workout plans and routines
├── diet.html            # Diet and nutrition guides
├── community.html    # Community page
├── stories.html        # Success stories / testimonials
├── contact.html        # Contact form / info
├── style.css              # Global stylesheet
├── script.js              # JavaScript functionality
└── README.md

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Multi-page navigation (Home, About, Workout, Diet, Community, Stories, Contact)
- Interactive UI elements powered by Vanilla JS
- Clean and modern layout with custom CSS styling
- No frameworks or libraries — pure HTML/CSS/JS
- Fast load times, lightweight codebase

## 🚀 Getting Started

### Prerequisites

You just need a web browser. No installations, build tools, or dependencies required.

### Installation

1. Clone the repository

```bash
   git clone https://github.com/cheshta02/fitverse.git
```

2. Navigate into the project folder

```bash
   cd fitverse
```

3. Open `index.html` in your browser
   - Simply double-click `index.html`, **or**
   - Use the **Live Server** extension in VS Code for a local dev server experience

## 📄 Pages Overview

- **index.html** – Landing/home page with hero section and navigation
- **about.html** – Information about FitVerse and its mission
- **workout.html** – Browse various workout routines and exercises
- **diet.html** – Diet plans and nutrition tips
- **community.html** – Connect with other fitness enthusiasts
- **stories.html** – Real success stories and testimonials
- **contact.html** – Get in touch via a contact form

## 🔮 Future Improvements

- 🤖 **AI Chatbot Integration** – Add a smart chatbot to answer fitness/diet queries and guide users through the site
- 🔐 **User Authentication** – Allow users to sign up/log in and save personalized workout & diet plans
- 📊 **Progress Tracker** – Add a dashboard to track workouts, weight, and body measurements over time
- 🌙 **Dark Mode** – Toggle between light and dark themes
- 📱 **PWA Support** – Make the site installable and usable offline
- 🗄️ **Backend Integration** – Connect to a database (e.g. Firebase/MongoDB) for dynamic content like community posts and stories
